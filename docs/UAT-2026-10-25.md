# Portfolio smoke tests and acceptance scenarios

Tested locally at http://localhost:5174 on 2026-10-25 using Chromium.

## Passed checks

- Ten public routes rendered at 1440px, 820px, and 390px without JavaScript page exceptions or horizontal overflow: Home, Projects, Services, Studio, Packages, Careers, Insights, Contact, Privacy, and Terms.
- Hero artwork and caption tested at 1440px, 1024px, 820px, 390px, and 320px. Caption remains inside the actual image. Final lower inset is 12px on larger screens and 8px on phones.
- Contact: required-field validation, package subject prefill, topic selection, error recovery with draft retention, success state, and form reset. Submission responses were intercepted; no real messages were sent.
- Packages: category filter, monthly preference, and contextual link into Contact. Mobile app package defaults to Without AI. Selecting With AI passes that choice into the contact subject along with product and payment preference.
- Careers: clipboard success and feedback, copy/check icon, refresh icon, retry request, email fallback, role filtering, modal opening and Escape closing. Role data was intercepted for tests because the live feed is unavailable.
- Mobile/tablet menu: custom icon, opening, Escape closing, navigation, and close-on-navigation. Desktop navigation remains available above 1024px.
- Branded loader: visible during a deliberately delayed local module request and removed once the page is ready. No artificial minimum loading delay or fake percentage is used.
- Home process selector changes content. Projects and packages retain their filter controls.
- Custom 404 renders and its Home link recovers correctly. Mobile layout has no horizontal overflow.
- Unauthenticated candidate dashboard and callback without a code both return to Careers.
- Services Sales Incentive image has zero horizontal frame gap and zero gap above its caption at 1440px, 820px, and 390px. Its rendered ratio matches the source. Home and Projects use the source ratio with zero image padding.
- All five favicon links return HTTP 200. ICO contains 16px, 32px, and 48px PNG frames; separate PNGs are 96px, 180px, and 192px.

## Content and image audit

Home main content contains five distinct image sources and no repeated heading or paragraph strings. Its chooser, service summary, process, and package section serve different visitor decisions. The shared footer intentionally repeats the brand tagline and contact route.

Careers no longer reuses the home loop image. Its new illustration appears only on Careers and is also visible on mobile. The home hero appears only on Home.

Project artwork remains shared where the same project is previewed on Home, Projects, and Services. Fidelity artwork also appears on Studio and Insights as a research visual. These cross-page repetitions are recorded rather than represented as unique images.

## Limits and outstanding dependencies

- The live IMS request to api.looplab.lk failed DNS resolution. Retry works, but frontend changes cannot restore that host. Direct email applications remain available.
- Contact success/error tests used intercepted responses. Live Formspree delivery and mailbox receipt were not tested.
- Authenticated dashboard and real OAuth login require a working IMS and user credentials; only guest recovery was tested.
- Browser tests are simulated acceptance scenarios, not final human stakeholder sign-off or physical-device certification.
- ESLint has one existing CandidateDashboard useEffect dependency warning. No lint errors were reported.
